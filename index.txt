Write a short script using variables, arithmetic operators, and a switch statement that calculates a final grade based on a numeric score out of 100 divided into ranges for grades A, B, C, D, and F.

// Input variables
const totalPoints = 87;
const maxPoints = 100;

// Calculate percentage score
const score = (totalPoints / maxPoints) 100;

// Map the score to a range indicator for the switch statement  w
// Math.floor(score / 10) gives: 10 or 9 for A, 8 for B, 7 for C, 6 for D, and < 6 for F
const scoreBracket = Math.floor(score / 10);

let grade;

switch (scoreBracket) {
  case 10:
  case 9:
    grade = "A";
    break;
  case 8:
    grade = "B";
    break;
  case 7:
    grade = "C";
    break;
  case 6:
    grade = "D";
    break;
  default:
    grade = "F";
}

console.log(`Score: ${score}% | Final Grade: ${grade}`);
// Output: Score: 87% | Final Grade: B

Describe how the && (AND) and || (OR) operators use short-circuit evaluation. How can this be used to provide default values for variables?
If the left-hand operand is falsy, the overall expression must be false. It "short-circuits" and returns the left value immediately, ignoring the right-hand side.
If the left-hand operand is truthy, it continues and returns the right value (regardless of whether the right side is truthy or falsy).

If the left-hand operand is falsy, the overall expression must be false. It "short-circuits" and returns the left value immediately, ignoring the right-hand side.
If the left-hand operand is truthy, it continues and returns the right value (regardless of whether the right side is truthy or falsy). answer
left is Falsy: The && operator knows the total condition can never be true, so it short-circuits and returns that left falsy value immediately (e.g., 0 && "Hello" returns 0).
Left is Truthy: The outcome depends entirely on the second value, so it moves to the right side and returns whatever value is there (e.g., "Cat" && "Dog" returns "Dog").

 Initialization: Runs once before the loop starts to set up counter variables (e.g., let i = 0).
Condition: Evaluated before every iteration. If true, the loop body executes; if false, the loop terminates.
Final-expression (Update): Evaluated at the end of every iteration, right after the loop body completes and immediately before the condition is checked again (e.g., i++).

What is a "loop invariant," and how does a programmer ensure a while loop eventually reaches its termination condition?
A loop invariant is a logical assertion or condition that is true before and after each iteration of a loop. It serves as a mathematical/formal proof that a loop is doing what it is designed to do.
While the variables inside the loop change during an iteration, the core relationship described by the loop invariant remains unchanged.

Define the arguments object vs. the "Rest Parameter"
In JavaScript, both the arguments object and rest parameters (...args) allow a function to accept an indefinite number of arguments. However, rest parameters are the modern (ES6+) standard and fix several fundamental design flaws of the legacy arguments object.
